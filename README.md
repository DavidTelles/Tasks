# 📂 Tasks — Pequenos Projetos Web

Este repositório contém **projetos pequenos** que uso para praticar lógica de programação, DOM, eventos e manipulação de tempo.

## 🚀 Projetos

### 🧮 Calculator  
Uma **calculadora** Permite realizar operações básicas e treinar manipulação de eventos e DOM.

---

### ✊✋✌ Jokenpo  
Jogo do **Pedra Papel Tesoura** feito apenas com JavaScript.
---

### ⏱️ Pomodoro  
Simulador do **Método Pomodoro**, técnica de gerenciamento de tempo.

## 📌 Como usar
1. Clone o repositório  
```bash
git clone https://github.com/DavidTelles/Tasks.git
```
2. abaixe a biblioteca prompt-sync
```bash
npm i prompt-sync
```
3. Use o node para rodar ou abra o arquivo em algum browser
```bash
node index.js
```
